How it works

  1. Preprocess. The image is resized to 224×224 and normalized with ImageNet statistics — the same pipeline used in training and evaluation.
  2. One CNN pass. A fine-tuned EfficientNet-B0 convolutional network extracts artifact and texture features and outputs a single fake-probability.
  3. Verdict. Probability above 0.5 → Fake, otherwise Real, reported with the model's confidence.

Trained and evaluated on face imagery from the Celeb-DF v2 benchmark (real celebrity / YouTube face videos vs. high-quality face-swap deepfakes), with a video-level train/test split so no video leaks across sets. It detects AI-generated / manipulated face imagery; it is a research demo, not a forensic tool.
